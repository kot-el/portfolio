Мен туралы

Astana IT University колледжінің 1 курс студентімін, мамандығым - "Бағдарламалық қамтамасызтандыру". Қазіргі таңда Python, HTML бағдарламалау тілдерін тереңдетіп оқып жатырмын. Қазіргі мақсатым - теориялық білімімді практикалық құралдарға айналдарыру. Жұмыста дизайн мен функционалдыққа мән беремін.

Дағдылар

Бағдарламалау тілдері: Python(негіздері, тізімдер мен сөздіктермен жұмыс), SQL(негізгі SELECT, JOIN сұраныстары)

Веб-әзірлеу: HTML5, CSS3(макет бойынша беттеу)

Құралдар: Canva

Қосымша: ағылшын тілі(B1)

Жобалар

API жобасы: Кітапхана жүйесі (Library API)

  • Мақсаты: Кітаптардың каталогын басқаруға арналған серверлік бөлік.
  • Технологиялар: Python, PostgreSQL.

Автоматтандыру скрипті: Файлдарды басқару жүйесі

  • Мақсаты: Компьютердегі файлдарды кеңейтілуіне қарай (суреттер, құжаттар, видеолар) автоматты түрде сәйкес папкаларға бөлу.
  • Технологиялар: Python.

Деректерді өңдеу жобасы: Ауа райы болжамы (Weather App)

  • Мақсаты: API арқылы нақты уақыттағы ауа райы деректерін алу.
  • Технологиялар: Python, OpenWeatherMap API.
